dokidoki 字幕播放器 · 离线版
================================

一、怎么用
--------------------------------
1. 把整个文件夹解压到任意位置（路径里有中文也没问题）。
2. 双击「启动 dokidoki.cmd」。
3. 浏览器会自动打开 http://localhost:3000/ ，开始使用。
4. 用完直接关掉那个黑色命令行窗口，服务就停了。

就这么简单，不需要安装 Node、Python 或任何运行环境。


二、为什么不能直接双击 index.html
--------------------------------
app 文件夹里的 index.html 是 Vite 构建的 ES Module 应用，
浏览器出于安全限制不允许用 file:// 方式加载模块脚本；
另外 FFmpeg WASM 需要 SharedArrayBuffer，必须由服务端下发
COOP / COEP 响应头。所以必须走一个本地 HTTP 服务。

启动脚本用 Windows 自带的 PowerShell 起服务，零安装依赖。
（不要直接双击 app\index.html，会白屏。）


三、如果浏览器没自动打开
--------------------------------
手动在地址栏输入：http://localhost:3000/

如果提示端口被占用，启动脚本会自动从 3000 往后找空闲端口，
具体端口号会打印在黑色窗口里，照着输入即可。


四、支持的文件格式
--------------------------------
音频 / 视频：能不能放，取决于浏览器自己会不会解码。

  没问题：mp3、wav、flac、ogg、m4a、aac、opus
  一般没问题：mp4、mov、webm、mkv（里面是 H.264 / H.265 + AAC）
  基本放不出来：avi、wmv、flv

本版本没有做「抽音轨」兜底，遇到放不出来的格式，
先用别的工具转成 mp4 或 mp3 再用。

字幕 / 歌词：lrc、srt、vtt、ttml、xml
字体：ttf、otf、woff、woff2

拖入时可以直接把「媒体 + 字幕」一起拖进来，
即使两个文件名完全不一样也能自动配对。


五、几个好用的点
--------------------------------
· 悬浮视频小窗：视频只在左侧小窗播放，主画面背景保持不变。
  按 W 键可以显示 / 隐藏；关掉后点底部「恢复视频小窗」按钮也能找回来。
  窗口可以拖动、可以拖右下角缩放，位置和大小会记住。
· 字幕对齐：底部十字准星按钮。点选某一行字幕，它会吸附到附近
  最强的起音点，并据此整体平移时间轴。
  在文件开头和结尾各点一行（两个锚点），会自动做线性插值，
  修正「越往后越偏」的漂移。
· 中英文切换：右上角「中文 / EN」按钮，设置面板也会一起切换。
· 完全离线：加载后不再请求任何外部地址，可以断网使用。


六、想自己改代码
--------------------------------
源码在这个仓库里：
https://github.com/pandipper/dokidoki-immersive-audio-player-lyric-video-maker

  npm install --legacy-peer-deps     ← 必须带这个参数
  npm run dev                        ← 开发
  npm run build                      ← 构建到 dist/

构建产物就是本压缩包里 app 文件夹的内容。


七、遇到问题怎么办
--------------------------------
· 双击后窗口一闪就没了
  Windows 的脚本执行策略挡住了。在本文件夹的地址栏里输入 cmd 回车，
  然后手动敲这一行（路径按实际情况改）：
    powershell -ExecutionPolicy Bypass -File "server.ps1" -Port 3000

· 页面白屏
  看地址栏是不是以 http://localhost:3000/ 开头。
  如果是 file:///... 开头，说明直接打开了 index.html，请改用启动脚本。

· 提示端口被占用
  脚本会自动从 3000 往后找空闲端口，具体号码打印在黑色窗口里，
  照着那个号码访问即可。

· 浏览器没有自动打开
  手动访问 http://localhost:3000/ 。

· 想换端口
    powershell -ExecutionPolicy Bypass -File "server.ps1" -Port 8080
